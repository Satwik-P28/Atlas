# Changelog

All notable changes to Atlas. This project is a research system; entries describe behaviour and
research records, not marketing milestones. Versions before 0.2.0 are engineering phases of the
research programme and are documented under `docs/`.

## [0.2.0b1] — v0.2.0-beta.1 — 2026-11-23

First integrated release candidate. It combines the FOCUS certificate stack, the financial-answer
semantics and geometry work, the prospective holdout, the price-movement intelligence stack, certified
revision impact and the ALFRED vintage study into one tree, and adds the release engineering needed to
install and audit it.

### Added

- **Release integration branch** `release/v0.2.0-beta.1` with a non-destructive history: the FOCUS and
  financial-answer stack, the v3.2 price-intelligence stack, certified revision impact (CRI) and the
  real-time vintage study (ALFRED) are merged rather than replayed, so each workstream keeps its
  provenance.
- **Self-contained installation.** The wheel now bundles the demonstration fixture subset and the
  built terminal. `atlas demo` and `atlas serve` work from an installed artifact with no source tree,
  no Node toolchain and no network.
- **Release build and manifest tooling.** `scripts/build_release_artifacts.py` stages fixtures and
  frontend assets, builds the wheel and sdist, writes `SHA256SUMS` and an artifact manifest with a
  dependency inventory. Hashing is explicitly not presented as signing.
- **Distribution audit.** `scripts/audit_distribution.py` scans the tracked tree and reachable history
  for restricted vendor data and credential shapes, and writes a machine-readable report.
- **Source-rights inventory.** `docs/DATA_RIGHTS_INVENTORY.json` records a rights basis for every
  tracked data class; a test fails if a data path has no entry.
- **Local API host guard.** Foreign `Host` headers are refused (`421`) and cross-origin state-changing
  requests are refused (`403`), which closes DNS rebinding against the unauthenticated local service.
- **Release gates.** `docs/RELEASE_GATES.json` and `docs/RELEASE_READINESS.md` record gate-by-gate
  state with evidence and commands.
- **Public documentation set**: README, quickstart, user guide, troubleshooting, known limitations,
  security policy, contribution guidelines, code of conduct, citation metadata, licensing status and
  data-provider notes.

### Fixed

- **Stale schema pin in the reproduction script.** `scripts/reproduce_phase9_2.py` asserted
  `fresh_schema == 13` while the migration chain had reached 14, so hosted CI failed on a
  deterministic-reproduction step that looked like a serialisation defect. It now compares against
  `LATEST_VERSION`; a regression test executes the script and asserts the committed reproduction
  artifact is regenerated byte-for-byte.
- **Availability-model conflict between two evidence stacks.** The price-evidence resolver treated
  every document whose availability was modelled (precision `unknown`) as uncitable, which would have
  made every ingested filing unusable in a price investigation after the Phase 9.6.1 correction. A
  modelled bound now resolves as `modeled_bound` with `availability_is_upper_bound: true`, keeps the
  stored `unknown` precision, and raises a disclosure warning; genuinely unknown timing still refuses.
- **Version drift.** `pyproject.toml` said 0.2.0, `atlas.__version__` said 0.1.0 and the web package
  said a third thing. The package attribute is now the single source, `pyproject.toml` reads it
  dynamically, and `/api/health` reports the release separately from the pinned HTTP contract version.
- **Undeclared test-time solvers.** The decision tests compare against OSQP and Clarabel, which were
  not declared anywhere, so a clean install silently lost the cross-check. They are declared in the
  `optimization` extra and installed by CI, with a test pinning both facts.

### Preserved

- Frozen answer-semantics artifacts: the first-run holdout results (baseline 23/47, geometry 33/47),
  the original gold labels, the preregistration and the append-only adjudications are unchanged and
  hash-verified by the archive audit.
- The historical research record is not reinterpreted as a new independent evaluation: the 47-question
  cohort remains post-holdout development data.

### Release status at v0.2.0-beta.1

- **Licensed:** Apache-2.0 applied with `Copyright 2026 Satwik Peddireddi`; the artifacts built after
  the grant carry the licence metadata and notices, and every pre-licence hash is superseded.
- **Data:** no restricted vendor material exists in the tree or in any artifact; nine Nasdaq/Alpha
  Vantage files remain reachable only in the development repository's earlier history, which is to be
  renamed `Atlas-development` and made private. Restricting visibility does not recall copies already
  downloaded.
- **Publication:** every engineering and licensing gate passes; the GitHub administrative steps
  (rename, visibility, repository creation, release, Pages) and the PyPI upload were not executed
  because this environment holds no administrative credentials. See
  `docs/PUBLIC_RELEASE_HANDOVER.md`.
- **Not run:** no independent human usability evaluation exists.
