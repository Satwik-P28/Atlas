# Phase 9.5 — retrieval benchmark

## 1. Pre-registered thresholds

Declared in `scripts/phase9_5_benchmark.py` **before** inspecting results:

| Gate | Threshold |
| --- | --- |
| hit@5 | ≥ 0.70 |
| citation support | ≥ 0.90 |
| future leak rate | = 0.00 |
| abstention recall on unanswerable | ≥ 0.80 |

The question set is authored in the script, not generated by a model, and scored mechanically: a
hit requires a retrieved passage containing **all** required terms; a leak is any returned
document whose availability is later than the question's cutoff.

## 2. Corpus

6 real SEC documents (Apple and JPMorgan 10-K/10-Q), 6,551 passages, 698 tables, 27.5 MB.
`var/phase9_5.db`, schema 14.

## 4. What failed, and what it changed

- **Abstention was 0.0** on the first run. BM25 OR semantics matched the word "schedule" for a
  bitcoin question. Added the absent-term rule; abstention recall became 1.0.
- **One answerable question abstains** (`jpm-credit-risk`, "credit risk concentration"): the word
  *concentration* does not occur in the JPM passage set, so the absent-term rule fires. This is a
  precision/recall tradeoff, reported rather than hidden. A stricter rule (rarest-term presence)
  was tested and increased issuer-scoped false abstention further, so it was rejected.
- **Two historical questions were vacuous** at their original 2024/2023 cutoffs because the corpus
  starts in 2024. The cutoffs were moved to June 2026, where the FY2026 filing genuinely exists and
  must be excluded. Without that correction the "no leak" gate would have passed on an empty set.

## 5. Honest limits

- 13 questions, 6 documents, one engineer authored both questions and scoring rules. This is a
  smoke benchmark, not an independent financial-QA evaluation.
- No human-reviewed reference answers exist yet; scoring is term presence at passage level.
- No dense, hybrid or reranked baseline was run, so no architecture comparison is claimed.
- Only two issuers, both large US filers, both from the same EDGAR interface.
- Questions are English, keyword-bearing, and were written after reading the corpus structure;
  they favour lexical retrieval.
- Latency is warm-cache, single-process, local SQLite, and includes snippet generation.

## 6. Reproduce

```bash
python scripts/phase9_5_ingest.py --db var/phase9_5.db --cik 0000320193 --forms 10-K,10-Q --limit 2
python scripts/phase9_5_ingest.py --db var/phase9_5.db --cik 0000019617 --forms 10-K,10-Q --limit 1
python scripts/phase9_5_benchmark.py --db var/phase9_5.db --out artifacts/phase9_5_benchmark.json
```
The script exits non-zero if any gate fails, so the result cannot be reported as green by accident.
