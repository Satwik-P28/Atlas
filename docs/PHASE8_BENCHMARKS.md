# Phase 8 benchmarks

Measured on 2026-11-05 with Python 3.12.3, Linux 6.1.102 x86_64, 2 vCPUs. The package is the
pinned 47,270-byte fixture with SHA-256
`92ab1bf753438a0f534a080697abca9c638da11521e13c1dc43700883c82227b`.

| Operation | Runs | Min | Median | Max | Semantics |
| --- | ---: | ---: | ---: | ---: | --- |
| Package build | 3 | 23.829 ms | 23.904 ms | 26.033 ms | same saved run, repeated deterministic build |
| Install | 3 | 5.415 ms | 5.426 ms | 7.273 ms | fresh schema-10 database each run |
| Verify | 3 | 2.512 ms | 2.526 ms | 3.128 ms | re-read package bytes and validate hashes |
| Execute | 3 | 25.646 ms | 25.761 ms | 28.239 ms | model fit plus FEC scenario, no network |

Peak process RSS was 49.95 MB. The repeated build SHA-256 was
`5c78ce1e4867e3c3674dbe756aaf8b59fd431d19890b0033f3d8a246d4b83276`; it differs from the pinned
fixture because a recomputed analysis carries a new `generated_at` provenance timestamp. Builds
from the same saved run were byte-identical in all three runs. This distinction is intentional:
the fixture is the release artifact, not a claim that regenerating an analysis is a pure function
of wall-clock time.

The report is generated by `scripts/benchmark_phase8.py` at
`artifacts/phase8_benchmark.json`. It excludes interpreter startup, browser rendering and network.
No performance claim is made for other hardware. Execution is local and single-process.
