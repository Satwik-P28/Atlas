# Source rights for the FOCUS material

Scope: everything added or touched by the FOCUS work on this branch.

## SEC filings

- **Status:** US public record. `source.redistribution` is `public_domain`; document rights are
  classified at ingest (`atlas.research.rights.classify`), and ingestion refuses untrustworthy
  rights claims.
- **What is committed:** no filing bytes. `var/` is git-ignored. The committed artifacts contain
  accession numbers, SHA-256 digests, row/column coordinates and short printed cell strings such as
  `"34,229"` — the minimum needed for a certificate to be checkable.
- **What is not committed:** the archived original documents (`var/focus/snapshots/`, 37 MB for four
  filings). `scripts/focus_corpus.py` regenerates them from EDGAR.
- **SEC fair access:** a declared contact `User-Agent` is required; the corpus builder fails with an
  explicit message when `ATLAS_SEC_USER_AGENT` is unset, and throttles to 0.2 s between requests.

## FinanceBench

- **Status:** Patronus AI `financebench`, licensed CC-BY-NC-4.0. Not redistributable in this
  repository.
- **Current tree:** contains no question text, answer text or dataset rows. References to
  `financebench` in `artifacts/` and `docs/` are metadata, methodology and status records, and the
  corpus builder reads question rows from a path outside the repository (`/tmp/...`).
- **History:** commit `d8ae4f1` committed evaluation output derived from that dataset. Commit
  `6863024` removed the licensed material from the tree. **The old commit remains in history**; the
  tree is clean, the history is not.
- **Consequence for release:** a normal merge or promotion does not sanitise ancestor commits. If the
  repository is ever made public, or if history sanitisation is required, that is a separate,
  explicitly authorised history rewrite. This branch does not perform one and does not claim one.

## Third-party market data

`fixtures/` contains no restricted vendor market data. The `research-integrity` CI job enforces this
by failing if any tracked fixture filename contains `nasdaq_` or `alphavantage`. The Phase 9.2
reproduction additionally asserts that a specific restricted price (`289.91`) is absent from the
exported package bytes.
