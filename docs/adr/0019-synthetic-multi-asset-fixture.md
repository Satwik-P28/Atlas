# ADR 0019 — Use a clearly synthetic multi-asset fixture

**Status:** accepted (Phase 5)

## Context

Phase 4 has one real IBM price series and no licensed multi-security history. Testing
alignment, covariance, optimization and walk-forward selection requires a cross-section
with stable identities, membership dates and a delisting path. Scraping an unofficial
source or inventing “real” vendor rows would violate the evidence contract.

## Decision

Ship a deterministic four-instrument synthetic universe generated by a documented LCG,
with a content hash and explicit `data_class: synthetic_fixture`. Keep one delisted path.
Exclude it from the active return matrix rather than forward-filling. Never mix synthetic
rows with IBM's real vendor bars.

## Consequences

Engineering and mathematics can be tested reproducibly. No result supports a claim about
real markets, market-wide coverage or survivorship-bias-free research. A real provider and
membership history remain Phase 6 prerequisites.
