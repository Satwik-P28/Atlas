# Sixty-second demonstration script

Recorded against the release build with the offline demonstration database. Say what is on screen;
do not narrate capability that is not being shown.

**0:00 — the claim.** "Most tools give you a number. Atlas gives you a number you can challenge:
the exact source cell, the arithmetic, an independent check, or a refusal with a reason."

**0:08 — ask.** Answer certificates → company *Atlas Demonstration Industries* → concept
*gross profit* → period `2023` → **Resolve answer**. "21,690. One cell. Statement, accession,
table and unit ids, raw text `21,690`, currency USD, scale 10^6."

**0:22 — cite.** Point at *Row* / *Column* / *Accession*. "This is the citation, not a footnote:
the value is that cell or nothing."

**0:30 — verify.** **Build certificate** → **Verify independently**. "A second verifier re-reads
the pinned document bytes and recomputes. Fingerprint, not signature — it proves consistency, not
that my reading is right."

**0:40 — refuse.** Change the period to `1999` → **Resolve**. "Refused, with the reason. No
approximation, no interpolation, no plausible-looking number."

**0:48 — reproduce.** Close with the reproduction claim: "The same question on a second
installation returns the same value and the same source-table hash. That is what reproducible
research means here."

**0:56 — honesty.** "Records that are not filed stay unavailable: Atlas won't back-fill history.
It is local-only, unauthenticated, and an experimental preview."

Do not claim: institutional readiness, market-data coverage, guaranteed returns, or that a
verified certificate means the interpretation is correct.
