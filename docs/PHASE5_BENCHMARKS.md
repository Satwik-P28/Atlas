Measured 2026-11-05 on Linux 6.1.102 x86_64, glibc 2.39, Python 3.12.3, single process,
CPU only. Workloads are deterministic and run without a database or network.

## Interpretation

* Curve loading is dominated by reading and parsing the 2024 CSV, not by the bootstrap.
* Bond and option math is not a research bottleneck.
* Risk is the cost of a pure-Python covariance loop; 87 ms is acceptable for interactive use.
* Optimization is the slowest single request (294 ms) because it enumerates 3³ active sets
  and recomputes covariance per call. It is still below a second for three assets.
* A 3-fold walk-forward (more than 30 candidate runs plus cost sensitivity and a bootstrap)
  completes in about 0.30 s. Throughput is sufficient for this scoped fixture.
* No Rust/C++/GPU rewrite is justified by these measurements.

## What is not measured

* Concurrent requests, SQLite writes, or UI rendering time.
* Real multi-security data ingestion.
* A large universe (the optimizer is limited to eight assets).
* Statistical power or predictive value; latency is not evidence of either.

## Reproduction

```bash
.venv/bin/python benchmarks/phase5_bench.py
```

The script overwrites the JSON artifact and prints the same payload. Timings vary with
host load; the committed JSON records the run above.
