# Code of conduct

## Our commitment

This project is a technical research effort. Participation requires treating other people as
colleagues: assume competence, argue about evidence, and keep disagreement about ideas.

## Expected behaviour

- Critique claims, code and evidence, not people.
- State uncertainty. "I could not reproduce this" is a useful contribution.
- Accept correction, and correct the record when you were wrong.
- Respect data rights and confidentiality: do not post licensed data, private filings, credentials or
  someone else's unpublished work.
- Respect the project's integrity rules — no fabricated measurements, no quietly weakened tests.

## Unacceptable behaviour

- Harassment, intimidation, or discriminatory comments about a person or group.
- Personal or political attacks unrelated to the work.
- Publishing others' private information without permission.
- Sustained disruption of discussion, or bad-faith "contributions" that ignore reviewed decisions.
- Presenting fabricated results, citations or evaluations as real.

## Scope

This applies to repository discussions, issues, pull requests, reviews and any project space.

## Enforcement

Report a problem to the repository maintainer via
<https://github.com/Satwik-P28/Atlas>. Reports are handled privately. Responses scale with severity and
history: a clarifying message, a request to stop, removal of a contribution, or a ban from the project
space. The maintainer will state the reason for any action taken.

This code is project policy, not a legal document, and it does not create obligations for third
parties.
